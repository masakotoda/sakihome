# sakilingo

## Summary
趣味の英語。TOEIC 990点達成後の英語力維持のためのプログラム。または英語を趣味として楽しむプログラム。Duolingoの英語レベルでは物足りない自分のために作りました。

## How to run
Web ブラウザで https://masakotoda.github.io/sakilingo/ を開く。

## How to customize
1. ターミナルで以下のコマンドを実行。
```
$ git clone https://github.com/masakotoda/sakilingo.git
$ cd sakilingo
$ python3 -m http.server
```
2. sentencesフォルダ内の .tsv ファイルをテキストエディタで編集する。
3. Webブラウザで http://localhost:8000 を開く。
